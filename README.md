## ✨ Функции

- 🖥️ **Графичен интерфейс** - Лесна употреба с GUI
- 📅 **Календар за дати** - DatePicker за избор на период
- 🎯 **Филтриране по дата** - Изтегляне само на бележки от избран период
- 📊 **Прогрес барове** - Проследяване по страници и брой бележки
- ⏱️ **Визуален таймер** - Показва изминало време в реално време
- 🔒 **Ръчно влизане** - Безопасно - без съхранение на пароли
- 📝 **Детайлни логове** - Пълна информация за процеса
- 💾 **Запазване с дати** - Всяка бележка има дата на покупка
- ⏸️ **Прекъсване** - Спиране на процеса по всяко време
- 📊 **Анализ на цени** - История на цените в XLSX + интерактивни графики
- 🌿 **Сезонен анализ** - HTML отчет за цените на плодове и зеленчуци през сезоните

### 🆕 Функция за анализ на цени

Новата функция "📊 Анализ → XLSX" анализира изтеглените касови бележки и създава Excel файл с:

- **История на цените** - Всеки артикул е ред, всяка дата е колона
- **Филтриране** - Показва само артикули, които са купени повече от веднъж
- **EUR конверсия** - Автоматична конвертация на стари цени (преди 01.01.2026) от BGN в EUR
- **Професионално форматиране** - Цветни хедъри, замразени редове/колони, бордъри

**Как да използвате:**
1. Изтеглете касовите бележки с "1. Старт"
2. Кликнете на "Анализ → XLSX + сезонен отчет"
3. Изберете създадения .txt файл (или папка с много файлове)
4. Получавате .xlsx файл със същото име + "_price_analysis", интерактивна HTML графика и сезонен отчет

## 📦 Алтернативни методи за инсталация

> **💡 Препоръка:** Използвайте новите `start.bat` или `start.ps1` скриптове, които автоматично правят всичко за вас!

### Изисквания

- Python 3.8 или по-нова версия
- Windows, Linux или macOS

### Опция 1: Автоматичен старт с инсталация (ПРЕПОРЪЧИТЕЛНО ⚡)

**Windows:**
```powershell
git clone https://github.com/reminchev/lidl-receipt-downloader.git
cd lidl-receipt-downloader
# Двоен клик на start.bat или:
.\start.ps1
```

**Linux/macOS:**
```bash
git clone https://github.com/reminchev/lidl-receipt-downloader.git
cd lidl-receipt-downloader
chmod +x start.sh
./start.sh
```

### Опция 2: Ръчна инсталация с venv

**1. Клонирайте репозиторито**

```bash
git clone https://github.com/reminchev/lidl-receipt-downloader.git
cd lidl-receipt-downloader
```

**2. Създайте виртуална среда**

```bash
# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux/macOS
python3 -m venv venv
source venv/bin/activate
```

**3. Инсталирайте зависимостите**

```bash
pip install -r requirements.txt
playwright install chromium
```

### Опция 3: Инсталация с Conda

**1. Клонирайте репозиторито**

```bash
git clone https://github.com/reminchev/lidl-receipt-downloader.git
cd lidl-receipt-downloader
```

**2. Създайте conda среда**

```bash
conda env create -f environment.yml
conda activate lidl-downloader
```

**3. Инсталирайте Playwright браузъри**

```bash
playwright install chromium
```

## 🚀 Употреба

### Стартиране

**Ако използвате venv:**
```bash
# Windows
.\venv\Scripts\activate
python lidl_scraper_gui.py

# Linux/macOS
source venv/bin/activate
python lidl_scraper_gui.py
```

**Ако използвате conda:**
```bash
conda activate lidl-downloader
python lidl_scraper_gui.py
```

**Без виртуална среда:**
```bash
python lidl_scraper_gui.py
```

### Стъпки

1. **Изберете период (опционално)**
   - Кликнете на календарите за избор на начална и крайна дата
   - Отметнете "✓ Филтрирай по период"

2. **Изберете директория** за съхранение

3. **Натиснете "1. Старт"**

4. **В отворения браузър:**
   - Влезте в акаунта си на Lidl.bg
   - Отидете на страницата с касови бележки

5. **Натиснете "2. Започни изтегляне"**

6. **Изчакайте завършване** - следете прогреса в реално време

## 📄 Изходен файл

Бележките се запазват във формат:

```
================================================================================
КАСОВИ БЕЛЕЖКИ ОТ LIDL.BG
Дата на изтегляне: 14.01.2026 15:30:45
Общо бележки: 25
Период: от 2024-01-01 до 2024-12-31
================================================================================

================================================================================
БЕЛЕЖКА #1
Страница: 1
Дата: 2024-05-15
================================================================================

[Съдържание на касовата бележка]
```

**Име на файла:** `lidl_receipts_ГГГГММДД_ЧЧММСС.txt`

## 🛠️ Решение на проблеми

### Не се намират бележки
- Проверете дали имате покупки в историята
